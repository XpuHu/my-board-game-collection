# Принцип интерфейса

Моя коллекция отвечает на вопрос:

```
Во что я играю?
```

Wishlist отвечает на вопрос:

```
Во что стоит поиграть?
```

Поэтому интерфейс этих разделов намеренно различается.

Коллекция максимально компактная и ориентирована на быстрые действия.

Wishlist представляет собой подробную энциклопедию с полной справочной информацией.
